# Chinese glossary (简体中文) — mayLEHUONG website

Simplified Chinese for mainland readers, elegant and concise. This is a luxury tailoring house: write natural Chinese marketing copy, not word-for-word. Translate from the Vietnamese; the English is only a reference for meaning.

## Fixed rules
- Brand names stay unchanged: mayLEHUONG, Lê Hương, mayLEHUONG FASHION COMPANY LIMITED.
- Legal name "Công ty TNHH Thời Trang Lê Hương" → "黎香时装有限责任公司 (Công ty TNHH Thời Trang Lê Hương)".
- Hotline numbers, emails, URLs, prices, product codes, sizes (S, M, XL, 2XL…): unchanged.
- Placeholders `{N1}` (product name), `{C1}` (product code), `{D1}` `{D2}`… (numbers): copy each one exactly, same count. You may move them. Never drop or add one.
- Material Symbols icon names (`shopping_bag`, `arrow_forward`, …) and other pure code tokens: return unchanged.
- Currency: keep `đ` / `₫` / `VNĐ` exactly as written after the number (the builder converts them). Do not convert to 元 or add currency words.
- Punctuation: use Chinese full-width punctuation inside Chinese sentences (，。：；！？「」（）). Keep the separators ` · `, ` | `, ` – `, `→` and leading/trailing ":" / "·" of a fragment as they are, because many strings are fragments of a sentence split by inline markup. The fragment must still read naturally when joined.
- ALL CAPS Vietnamese has no case in Chinese: just translate it (keep any Latin words in caps).
- Honorifics Anh / Chị / Quý khách → 您.
- No spaces between Chinese characters. Put a space between Chinese and Latin words/numbers only if it reads better; either is fine, be consistent: no space (e.g. `{D1}颗扣`, `mayLEHUONG高级定制`).
