# English glossary — mayLEHUONG website

Use these terms everywhere for consistency. American English, elegant and concise. This is a luxury tailoring house; write naturally, not word-for-word.

## Brand and fixed items
- mayLEHUONG, Lê Hương, mayLEHUONG FASHION COMPANY LIMITED: brand names, keep unchanged.
- Legal name "Công ty TNHH Thời Trang Lê Hương": "Le Huong Fashion Co., Ltd.".
- Hotline numbers, emails, URLs, prices, product codes: unchanged.
- Placeholders `{N1}` (product name), `{C1}` (product code), `{D1}` `{D2}`… (numbers): copy each one exactly. You may move them within the sentence. Never drop one. Never add a new one.
- Material Symbols icon names (`shopping_bag`, `arrow_forward`, …): never translate, return unchanged.

## Addresses and place names
- Keep Vietnamese proper names with their diacritics: Biên Hòa, Đồng Nai, Hà Nội, Tam Hiệp, Nguyễn Ái Quốc, Chính Vân, Chuyên Mỹ.
- Translate only the generic words:

| Vietnamese | English |
|---|---|
| Số | No. |
| Khu Phố | Quarter |
| Phường / P. | Ward |
| Thành Phố / TP. | City |
| TP.HCM | Ho Chi Minh City |

- Example: "1797 Nguyễn Ái Quốc, Khu Phố 10, Phường Tam Hiệp, Thành Phố Đồng Nai" → "1797 Nguyễn Ái Quốc, Quarter 10, Tam Hiệp Ward, Đồng Nai City".
- "Showroom Biên Hòa" → "Biên Hòa Showroom". "Showroom Hà Nội" → "Hà Nội Showroom".
