# Hindi glossary (हिन्दी) — mayLEHUONG website

## Style
- Write natural, polite Hindi marketing copy for a luxury tailoring house. Use आप forms and Devanagari script.
- Common fashion loanwords may stay in English, written in Devanagari where natural (सूट, ब्लेज़र, शोरूम) or in Latin where Indian shoppers usually see Latin (S, M, XL, AI).
- Translate from the Vietnamese. The English text is a reference for meaning.
- Digits stay Western (0-9).

## Fixed rules
- Brand names stay unchanged: mayLEHUONG, Lê Hương, mayLEHUONG FASHION COMPANY LIMITED.
- Legal name "Công ty TNHH Thời Trang Lê Hương" → "ले हुओंग फ़ैशन कंपनी लिमिटेड (Công ty TNHH Thời Trang Lê Hương)".
- These stay unchanged: hotline numbers, emails, URLs, prices, product codes, sizes.
- Placeholders `{N1}` (product name), `{C1}` (product code), `{D1}` `{D2}`… (numbers):
  - Copy each one exactly, with the same count.
  - You may move them. Never drop or add one.
- Material Symbols icon names (`shopping_bag`, `arrow_forward`…) and pure code tokens: return them unchanged.
- Currency: keep `đ` / `₫` / `VNĐ` exactly as written after the number. Do not convert to ₹.
- Sentence end: use the danda "।" for Hindi sentences. Keep ? and ! as they are.
- Many strings are fragments of a sentence split by inline markup:
  - Keep the separators ` · `, ` | `, ` – `, `→` and any leading or trailing ":" / "·".
  - The fragment must still read naturally when the pieces are joined.
- ALL CAPS Vietnamese: translate it normally (Devanagari has no case).
- Honorifics Anh / Chị / Quý khách → आप.
